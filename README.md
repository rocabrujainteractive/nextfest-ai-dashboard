# IA declarada en Steam Next Fest (octubre 2026)

Explorador interactivo del uso declarado de IA generativa en los 7.322 juegos del Steam Next Fest de octubre de 2026.

**Ver el sitio:** https://rocabrujainteractive.github.io/nextfest-ai-dashboard/

*English: interactive explorer of the AI-generated-content disclosures in the October 2026 Steam Next Fest.*

## Cómo leerlo

- Lo que se muestra es lo que cada estudio **declara** en Steam, no lo que realmente usa. Un juego sin declaración no prueba que no use IA.
- Las categorías de uso, el tipo de generación y los resúmenes son interpretaciones automáticas de un modelo de lenguaje y pueden tener errores.
- El panel no mide calidad ni originalidad y no etiqueta ningún juego como copia o de baja calidad.
