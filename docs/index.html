Sobre los datos

  • Hechos (Steam): el texto del “AI Generated Content Disclosure” es literal, tal como lo publicó cada estudio. Que un juego aparezca como “declara IA” sale solo de que esa sección exista en su página de Steam.
  • Análisis (LLM): las categorías de uso, el tipo de generación y el resumen los interpretó un modelo de lenguaje a partir de ese texto. Pueden contener errores; cada ficha muestra el texto original para comprobarlo.
  • Lo declarado no es lo verificado. Los datos reflejan lo que cada estudio dice, no lo que realmente usa. Un juego sin disclosure no prueba que no use IA.
  • Estado desconocido: algunas páginas (sobre todo contenido adulto) exigen iniciar sesión y no pudieron comprobarse; no se cuentan como “sin IA”.
  • Tipo de generación: “No claro” significa que el texto no dice si el contenido se generó antes del lanzamiento o en tiempo real.
  • Este panel no mide calidad ni parecido entre juegos, y no etiqueta ningún juego como copia o de baja calidad.
